Interpretation and release boundary

This dashboard is a planned test register, not a released Quanty-parity certificate. QES is intentionally omitted until the typed, feature-bound evidence validator and Roadmap/Periodic Table publication contract have been approved.

Existing accepted history remains immutable. Only the canonical sources can change maturity statuses. The public dashboard is a sanitized projection and never a source of truth.
