# Microscope Watch public view

Dit is een **afzonderlijke, statische publieksweergave**. De private repository `TuinvosLabs/Microscope-Watch` blijft eigenaar van code, historie en gegevens. Dit pad bevat uitsluitend expliciet geselecteerde openbare advertentiedata.

De huidige `data.json` is een lege, duidelijk als ongeverifieerd gemarkeerde beginstaat. Automatische cross-repo publicatie is nog **niet** ingericht. Wijzigingen in deze gedeelde Pages-repository verlopen via een eigen branch en PR, niet via directe writes naar `main`.

Niet publiceren: privé-repolinks, zoekrun-logs, verkopersidentiteiten, contactgegevens, intern runnerdetails of ongecontroleerde zoekresultaten.
