# XMDWorkbench public dashboards

Public, sanitized presentation outputs for XMDWorkbench.

This repository intentionally contains only derived viewer artifacts. Private source code, raw NAS evidence, runner identities, internal paths and private provenance remain in the private XMDWorkbench repository/evidence store.

## Published views

- `roadmap/` — Quanty functional roadmap evolution player.
- `evidence/` — reserved for the sanitized single-file scientific evidence dashboard.

Publication from the private source repository must remain a reviewed, sanitizing step; this repository is never the scientific source of truth.
